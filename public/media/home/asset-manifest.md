# sfireplace 首页素材确认清单

只生成素材，不接入页面。

## 文件夹
- ui-icons: CSS/SVG 风格 UI 小图标
- certifications: 认证展示 SVG
- category-illustrations: 产品分类小图，稍后会从分类参考图裁切
- section-illustrations: 首屏、工厂、案例、新闻等页面插图
- preview: 素材总览页面

## 设计方向
- 黑色/炭灰 + 橙色高亮
- 小卡片圆角控制在 6-8px
- 产品分类用干净白底产品图
- 工厂实力区使用厂房/车间拼图
- 认证区使用独立认证卡片，不直接用纯文字临时占位
